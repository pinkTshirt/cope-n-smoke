# Virtual Cigarette

A browser-based computer-vision interaction experiment where a virtual cigarette follows your hand and reacts to face/mouth movement.

> **Important:** smoking is **very** bad, does not promote in any way


## Requirements

- Node.js 20+ recommended
- A modern browser with webcam support
- HTTPS for deployed webcam access
- localhost works during development

## Run locally

```bash
npm install
npm run dev
